# Import and Kaggle latency repairs

PubChem 3D V2000 structures with ordinary bond/charge records are parsed in the browser worker without downloading the native engine. 2D, V3000, isotope/radical and unusual records keep the Open Babel path. Supplied 3D coordinates stay unchanged. Source bond orders and formal charges are preserved. A 20-entry, 15-minute in-memory cache returns independent molecule copies. Concurrent identical lookups share requests; a fast 3D response does not wait for the fallback 2D response. First-time 2D generation and force-field operations still need the pinned native engine. Native assets get deterministic gzip sidecars during the image build; HTTP negotiates gzip with the original MIME type and Vary: Accept-Encoding. Clients that disable gzip or request ranges receive original bytes. Compression never changes the verified engine contents and never runs in a user request.

Kaggle authentication verifies one remote list page, rather than enumerating all historical notebooks and reconciling Cloudflare before acknowledging login. Existing cached jobs are returned immediately; the existing browser synchronization refreshes authoritative state afterward. Post-push job metadata replication use a bounded two-worker queue, deduplicated by operation, with at most 32 pending operations. The calculation manifest and submission idempotency remain synchronous. Degraded replication remains best-effort, as before, and later status calls retry it. Capacity observations overlap at most four independent status requests and still query the newest window of each logical job.

A workflow dependency preferentially downloads only `.out`, `.inp` and `.xyz` outputs; preserved result archives and archive-only older kernels retain compatibility. Ownership is checked before downloads. Full result/checkpoint downloads remain available through the results routes. The optimization convergence and final-coordinate eligibility checks remain mandatory.

The browser queue uses one in-flight advancement per child. Delayed result publication, rate limits and temporary transport errors keep the stage waiting, with 10-90 second backoff for up to 30 minutes. Explicit scientific rejection stops the chain. A newer optimization never falls back to older or original coordinates. Cancellation/deletion during a pending handoff prevents later promotion. A successful handoff records the immediate parent ID and uses the existing stable submission idempotency key.

The wizard queue is still browser-dispatched: the page must remain available for later stages to be submitted. This change does not claim autonomous progression after all browser tabs are closed, nor does it bypass Kaggle scheduling delays, quotas, unavailable output files or PubChem outages. Previously failed, unsubmitted dependency stages have a **Retry this stage** action when their immediate predecessor is complete. It revalidates final coordinates and retries that child only; completed parent calculations are never submitted again. Cancelled/deleted stages and already-submitted remote kernels are not retried by this action.
